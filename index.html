DSH 生态的可信插件守门人 —— 由 dsh-plugin-verify 判定：验证为准入，徽标为判定，只收录通过运行时审查的插件。

插件作者：如何获得 Verified 徽标

  1. 准备一个 DSH 源码 checkout（pnpm run build:lib:host && build:lib:client 已构建）
  2. npx dsh-plugin-verify <你的插件路径> --repo <DSH checkout>
  3. 通过（7/7 waterfall）→ 提 PR/Issue 收录，附 verify-report.json

为什么要来：在 awesome 的"待测/未知"海洋里，Verified 徽标让你脱颖而出；验证还会帮你发现真实 bug（dsh-sentinel 案例）。验证方法学详见 官方 Discussion 462。

使用者：安装可信插件

从上方选一个 ✅ Verified 插件，然后：

dsh plugin --profile web add <插件包名>

（安装命令以插件自身 README 为准；Verified 徽标保证它至少通过了运行时审查。）
