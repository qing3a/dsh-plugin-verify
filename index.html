投稿你的插件（2 分钟上架）

这里是一个插件市场，不是一个清单。 投稿 = 验证 + 上架 = 获得徽标 + 被发现 + 被安装。

npx dsh-plugin-verify <你的插件路径> --repo <DSH checkout>
# ✅ 通过 | 捕获事件: 13 | waterfall: 7/7 | tools/result: 是
  1. 准备 DSH checkout（build:lib:host && build:lib:client）
  2. 跑上面的命令 → 通过
  3. 提 PR/Issue 投稿（附 verify-report.json，说明插件名/仓库/分类/一句话描述）
  4. 上架 → 获得徽标，进入分类目录

为什么要投稿：288+ 插件的"待测/未知"海洋里，✅ 徽标让你脱颖而出；验证顺带帮你发现真实 bug（dsh-sentinel 案例）；收录进分类目录 → 用户/AI 按功能找你 → 被安装。

使用者：安全安装

  1. 从目录选 ✅ 插件，查看验证日期（久于一周需谨慎——DSH 每天更新）
  2. dsh plugin --profile web add <插件包名>（以插件自身 README 为准）
  3. 先在隔离 profile 试加载，不提供生产密钥；保留配置与锁文件便于回滚

⚠️ 安装任何第三方插件前：查看源码、权限、依赖、许可证与验证日期。徽标 ≠ 安全审计。
