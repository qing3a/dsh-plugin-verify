# DSH 插件避坑案例库（Case Studies）

> dsh-plugin-verify 判定站出品。**赋能者视角**：写给插件作者与适配者，讲"写 DSH 插件会踩的坑、怎么避"——不是评审名单，不是背书。
> **素材边界**：只写我们自己亲历过的坑（验证 18+ 插件的实践 + 闭环案例），不写没验证过的结论；不评个体插件。
> **节奏**：有亲历素材才写，不凑数。

## 选题标准（什么样的坑会进案例库）

1. **我们亲历过**（验证管道里真实撞见，报告/闭环可查）——不写二手结论。
2. **适配者/作者真疼**（社区高频痛点的模式化表达）——不写自嗨。
3. **可操作**（每篇给读者能带走的清单）——不写纯现象描述。
